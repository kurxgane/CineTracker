# Histórico de desenvolvimento — CineTracker

Esta pasta reúne snapshots das versões anteriores do CineTracker. O objetivo é documentar a evolução do projeto, desde o primeiro buscador até a aplicação de biblioteca pessoal.

## Versões

| Versão | Conteúdo | Marco de evolução |
|---|---|---|
| [V1](v1/) | [Código](v1/buscador_omdb.py) e [README](v1/README.md) | Protótipo de busca e lista simples |
| [V2](v2/) | [Código](v2/dashboard.py) e [README](v2/README.md) | Biblioteca com status, notas e estatísticas |
| [V3](v3/) | [Código](v3/CineTracker-v3.py) e [README](v3/README.md) | Interface em páginas, pôsteres e busca em segundo plano |
| [V4](v4/) | [Código](v4/CineTracker-v4.py) e [README](v4/README.md) | Reformulação visual e layout adaptável |
| [V5](v5/) | [Código](v5/CineTracker-v5.py) e [README](v5/README.md) | Configuração externa da API e proteção dos dados locais |

## Sobre os snapshots

- Cada pasta preserva uma etapa específica do desenvolvimento.
- Os arquivos são versões históricas do código, não cópias completas e prontas para distribuição do aplicativo final.
- As bibliotecas Python precisam ser instaladas no ambiente antes da execução.
- Os arquivos de biblioteca pessoal, pôsteres e configurações locais não fazem parte do histórico publicado.
- A versão definitiva do projeto permanece na raiz do repositório.

As versões antigas são mantidas para fins de consulta e demonstração da evolução técnica e visual do CineTracker.
